# CampusNav V2 — API Reference

Base URL: `http://localhost:8000` (dev). The Vite dev server proxies `/api/*`,
`/auth` and `/health` to the backend on `:8000`.

Interactive OpenAPI docs: `http://localhost:8000/docs` (Swagger UI) and
`http://localhost:8000/redoc` (ReDoc), generated by FastAPI from the Pydantic
schemas in `backend/app/schemas/`.

## Authentication

Most endpoints require a bearer token. Obtain one via register/login, then send:

```
Authorization: Bearer <access_token>
```

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | `/auth/register` | — | Create account. Body: `{email, password, full_name}` (password min 8 chars) |
| POST | `/auth/login` | — | Body: `{email, password}` → `{access_token, token_type, expires_in}` |
| GET | `/auth/me` | token | Current user `{id, email, full_name, role, created_at}` |

## Navigation

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/navigation/campuses` | — | List campuses `{id, name, slug, description, featured, center_lat, center_lng}` (catalog metadata for the Explore hub) |
| GET | `/navigation/campuses/near?lat=&lng=&limit=&radius_m=` | — | Campuses ranked by haversine distance from a point, nearest first. Only campuses with a catalog centroid participate; `distance_m` is the honest great-circle distance in meters |
| GET | `/navigation/campuses/{slug}/stats` | — | Cheap catalog counts `{campus_id, campus_slug, buildings, nodes, entrances, landmarks, transit, poi, edges, surveyed_edges}` — no graph loading |
| GET | `/navigation/campuses/{slug}/graph` | — | Full graph: `{campus, nodes[], edges[], labels{}}` |
| GET | `/navigation/campuses/{slug}/nearest-node?lat=&lng=` | — | Snap a GPS fix to the closest walkable node; `distance_m` is honest, never invented |
| GET | `/navigation/campuses/{slug}/buildings` | — | Building list |
| POST | `/navigation/campuses/{slug}/route` | — | Compute a route. See below |

### Route request

```json
{
  "source_id": "<node-uuid>",
  "destination_id": "<node-uuid>",
  "require_accessible": false,
  "heuristic": "haversine",
  "mode": "shortest",
  "avoid_stairs": false,
  "alternatives": 3
}
```

- `mode`: `shortest` | `fastest` (walk-time-aware A\*)
- `require_accessible`: true excludes restricted edges and adds a penalty on
  unverified paths — an *honest* accessible route, see the README guardrails.
- `alternatives`: 0–3 additional routes.

### Route response

```json
{
  "status": "ok",
  "error": null,
  "route": {
    "source": "<node-id>", "destination": "<node-id>",
    "steps": [{ "from_node_id", "to_node_id", "edge_id", "distance_m",
                "estimated", "walk_time_min", "instruction" }],
    "total_distance_m": 1234, "estimated_walk_time_min": 18,
    "step_count": 6, "all_estimated": true, "summary": "Walk 400 m south…"
  },
  "alternatives": [ /* same shape */ ]
}
```

`status` values: `ok | unknown_node | source_equals_destination | no_path | invalid_graph`.

## Discovery / Search

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/search?q=&campus=&limit=` | — | Scored fuzzy search over buildings + graph nodes + POIs. Exact 100 / prefix 80 / word 70 / substring 45. Returns `SearchResult[]` `{id, label, type, category, lat, lng, campus_id, campus_slug, campus_name, subtitle, score}` |
| GET | `/campuses/{slug}/categories` | — | Real category counts `{key, label, count}[]` |
| GET | `/buildings/{id}` | — | Detail: entrances, floors, connecting nodes |

## Favorites (auth)

| Method | Path | Description |
|--------|------|-------------|
| GET | `/favorites` | List saved places (target deleted → row skipped) |
| POST | `/favorites` | Add. Body: `{target_type: "building"\|"node", target_id, note}`. Idempotent; 404 if the target doesn't exist |
| DELETE | `/favorites/{id}` | Remove (auth-scoped, 404 if not yours) |

## Preferences (auth)

| Method | Path | Description |
|--------|------|-------------|
| GET | `/preferences` | `{units, default_mode, default_avoid_stairs, default_require_accessible, theme}` — defaults applied on first read |
| PUT | `/preferences` | Partial update; omitted keys keep defaults/current values |

## Assistant (auth)

| Method | Path | Description |
|--------|------|-------------|
| POST | `/assistant/query` | Rule-based intent engine — no LLM required. Body: `{query, campus_slug?, user_location?, time_constraint_min?}` → `{kind: "route"\|"search"\|"info"\|"error", text, data?}`. `data.destination`/`data.results` carry real search hits for the UI to render as cards |

Example queries: *"Navigate to the CSE Block"*, *"Where is the library?"*,
*"I have a class in the Tech Park in 15 minutes"* (matches room + time constraint).

## Admin (role: admin)

| Method | Path | Description |
|--------|------|-------------|
| GET | `/admin/feature-flags` | Premium flag status + extension points |
| POST | `/admin/seed` | Idempotent re-seed from `backend/seed_data/` |

## Errors

All errors return the FastAPI shape: `{"detail": "<message>"}`. Auth failures
return `401`, missing targets `404`, validation `422` (see each schema).
